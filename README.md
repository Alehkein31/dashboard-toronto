# Toronto Analytics Dashboard

Live Demo: **https://dashboard-toronto.vercel.app**

A modern, responsive analytics dashboard built for the Toronto job market. Focused on performance, clean UI, and real-world features.

### 🚀 Features
- Dark/Light mode with localStorage persistence
- Dynamic data filtering (7d / 30d / 90d)
- CSV Export for reports
- Responsive grid (mobile-first)
- Animated metrics with Framer Motion
- Interactive charts with Recharts

### 🛠️ Stack
- React + Vite
- Recharts
- Framer Motion
- Vercel (Production)
